# Wetland Indicator Notes

## Working Question

Can WWF wetland restoration, reconnection, or protection areas be combined with flood-risk and population data to estimate the number of people who may plausibly benefit from nature-based flood mitigation?

## Early Indicator Shape

Potential first-pass indicator:

> People exposed to flood risk within a plausible wetland benefit area associated with WWF interventions.

## Open Decisions

- Which wetland intervention footprint data should be treated as the authoritative project area layer?
- Which flood-risk layer is available, globally consistent, and defensible enough for a June prototype?
- Should the first version estimate direct overlap only, downstream benefit areas, or both?
- Which population layer should be used for exposed people?
- Should vulnerability be included in the first prototype or documented as a second-stage refinement?
