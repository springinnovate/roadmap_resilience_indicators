# Data

Local data workspace for project inputs, intermediate model outputs, workflow assets, and final analysis results.

## Directory Structure

- `analysis_inputs/`: Data used as inputs to one or more analyses.
- `analysis_inputs/wwf_program_areas/`: WWF program, project, intervention, or place-based footprints.
- `analysis_inputs/zonal_units/`: Reporting or summarization units, such as watersheds, basins, countries, or other accounting geographies.
- `processing_outputs/`: Intermediate files written by models or scripts. These should generally be reproducible.
- `analysis_results/`: Final reports, tables, maps, and other shareable outputs.
- `workflow_assets/`: Configuration files and other small files that define or support analysis runs.
